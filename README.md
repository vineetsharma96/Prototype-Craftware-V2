✨ Animated Business Website — Project 2

A modern responsive frontend business website created as the second step in my web development journey.

Compared with my first project, this version focuses more on visual design, smooth animations, text transitions, image transitions, and overall user experience, while retaining direct WhatsApp communication.

---

🌟 Features

- 🎨 Modern responsive UI
- ✨ Smooth text animations
- 🖼️ Image transitions and animations
- 📱 Mobile-friendly design
- 💬 Direct WhatsApp messaging
- 🧭 Improved navigation experience
- ⚡ Interactive frontend elements
- 🤖 Experimental AI Chat Assistant

---

🎬 Animation & UI

A major goal of this project was to improve the visual experience compared with my first website.

The interface includes:

- Animated text elements
- Smooth image transitions
- Section-based animations
- Interactive UI elements
- Responsive layouts
- Improved visual hierarchy

The project helped me understand that a good website is not only about functionality but also about how users experience the interface.

---

🤖 AI Chat Assistant

I also experimented with integrating an AI-powered chat assistant.

The implementation was not fully functional in the final version.

Rather than considering this a failure, I treated it as a learning experience that showed me the importance of:

- API integration
- API authentication
- Backend communication
- Environment variables
- Request/response handling
- Security considerations when working with API keys

These lessons became important for my later full-stack projects.

---

💬 WhatsApp Integration

The website provides direct WhatsApp communication.

Users can initiate a conversation directly from the website, creating a simple communication flow:

Website → WhatsApp → Business
